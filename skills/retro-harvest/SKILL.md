# Retro Harvest

프로젝트 회고를 하네스에 되먹인다. 진화 루프의 마지막 단계다.

## 절차

1. 완료한 프로젝트의 `RETRO.md`에서 "하네스 개선점" 항목을 읽는다.
2. 각 개선점을 다음 중 하나로 분류한다:
   - 스킬 보강 — 기존 `skills/*/SKILL.md` 수정 또는 새 스킬 추가
   - 플레이북 보강 — `playbook/` 절차·체크리스트 수정
   - 템플릿 보강 — `templates/` 수정
3. 변경안을 사용자에게 보여주고 확인받는다.
4. 하네스 저장소에 브랜치를 만들어 변경을 커밋한다.
5. `CHANGELOG.md`에 변경 항목을 한 줄 추가한다.
6. PR 을 연다. `harness-ci.yml`이 통과해야 머지한다.

## 원칙

- 개선점이 모호하면 추측하지 말고 사용자에게 어떤 형태로 반영할지 묻는다.
- 한 회고에서 여러 개선점이 나오면 분류별로 커밋을 나눈다.
- 같은 개선점이 반복되면 더 근본적인 구조 변경을 제안한다.
- `skills`·`templates`·`playbook` 변경에는 반드시 `CHANGELOG.md` 갱신이
  따라간다. CI 가 이를 강제한다.
